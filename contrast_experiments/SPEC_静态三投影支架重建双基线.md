# 两篇论文的网络复现与静态三投影对比 Spec

**状态：**规格修订中；本文件只约束后续实现，不宣称已训练或复现论文数值。  
**日期：**2026-11-05

## 1. 目标与忠实度规则

实现以下两篇论文的 **DTE → 几何重建/反投影 → DTR** 工具重建分支，然后在用户的静态三投影任务中比较。两套网络均用 **PyTorch**。2021 年论文本来使用 PyTorch；2022 年论文本来使用 TensorFlow，后者是保留论文定义的 PyTorch 移植，不宣称二进制或随机训练轨迹完全等同。

| 代号 | 论文 | 原论文主设置 | 框架 |
| --- | --- | --- | --- |
| A | Eulig 等，*Deep learning-based reconstruction of interventional tools and devices from four X-ray projections for tomographic interventional guidance*，DOI: 10.1002/mp.15160 | 四投影，相邻 45°；DTE + 稀疏 FDK + 2.5D DTR | 原文及实现均为 PyTorch |
| B | Vöth 等，*3D Reconstruction of Stents and Guidewires in an Anthropomorphic Phantom From Three X-Ray Projections*，DOI: 10.1117/12.2646406 | 三投影，相邻 60°；DTE + 逐视角反投影 + 3D DTR | 原文 TensorFlow 2.5.0；实现移植到 PyTorch |

**忠实度标记：**下文用「原文明确」记录论文直接给出的设置；用「移植决定」记录原文未给出、但写代码必须决定的细节；用「任务适配」记录为了 0–60° 场景而改变的条件。任何任务适配的结果均标为 *adapted baseline*，不能称为论文原条件的数值复现。

本 Spec 的原文网络输出对象是**所有训练器械的联合三维二值分割**：A 包含支架、导丝、线圈，B 包含支架、导丝；两文均不是分别输出每个器械类别的多类分割，也未把“支架外包络轮廓”定义为输出。后续只在**仅含支架**的测试场景中把该联合输出作为支架杆件分割评价。如果评价外包络，必须另设真值及确定性的转换步骤，不得把杆件 Dice 当作外包络指标。

## 2. 原文 A：Eulig 等（2021）

### 2.1 原文数据和几何

1. **器械模型（原文明确）：**用 Blender Python API 建 600 个 STL 三维模型：导丝、支架、线圈各 200。支架从八种基础模型中选择，直径 `4.8–6.3 mm`、杆件厚度 `0.4–0.7 mm`，沿 NURBS 曲线变形并随机旋转；论文 §2.2.1 还列出导丝与线圈的生成范围。
2. **投影模拟（原文明确）：**多色能谱前向投影，按 Zeego C 臂几何模拟；器械材料按密度 `3.2–3.9 g/cm³` 的铁设置，使衰减与实物相近。DTE 训练时每个三维模型产生 17 幅、间隔 10° 的投影。DTR 训练时每个模型采用四幅、相邻 45°、随机起始角投影，稀疏 FDK 体素间距 `0.1 mm`，STL 体素化结果作标签。
3. **测量系统（原文明确）：**Zeego 的源探距 `1200 mm`、源到等中心 `785 mm`，探测器 `1240×960`、像素间距 `308 μm`；完整扫描共 496 幅投影。测量数据用于体模验证，不能把 496 幅误写成网络输入数。
4. **训练对象（原文明确）：**DTE 使用器械投影叠加患者 CBCT 投影。患者背景训练来自 4 次扫描（胸部 2、头部 1、骨盆 1），验证来自另 2 次扫描（胸部 1、腹部 1）。DTR 用模拟器械的理想、无噪声、仅器械投影训练；**原文没有在 DTR 训练中注入 DTE 假阳性/假阴性**。

### 2.2 A-DTE：二维器械提取网络

| 项目 | 原文明确的实现 |
| --- | --- |
| 任务 | 单幅含患者背景的投影 → 器械的连续投影值；目标是线积分/衰减值，不是二值掩膜。 |
| 结构 | 2D U-Net，编码与解码各四个阶段；每阶段两次 `3×3 Conv(stride=1, zero padding) → BatchNorm → SpatialDropout(p=0.2) → ReLU`。首层 64 通道，编码下采样后通道翻倍；`2×2` max pool、最近邻上采样再接 `3×3` 卷积、同尺度拼接跳连。DTE 输出用 ReLU。 |
| 初始化 | 卷积用 He 初始化；BN scale=1、bias=0。 |
| 数据处理 | 随机取 `384×384` 患者投影块并随机叠加器械块，剔除无或低衰减背景块；原文称器械投影沿 `x–y` 方向翻转以覆盖未模拟的 180°，未进一步列出每个翻转组合；模拟随管电流变化的 Poisson 量子噪声及标准差在 `0–1.4 px` 的高斯模糊。训练中用运行均值与方差将输入归一到零均值、单位方差；推理用训练统计量。原文未模拟造影剂。 |
| 训练 | L1/MAE；Adam `lr=1e-4, β1=0.9, β2=0.999`；batch size 6。原文未给固定 epoch 数。 |

### 2.3 A-DTR：连续切片输入的二维重建网络

| 项目 | 原文明确的实现 |
| --- | --- |
| 几何输入 | 四幅 DTE 输出按实际投影几何先组成**一个稀疏 FDK 体**。原文训练 DTR 时用理想的器械投影代替 DTE 输出。 |
| 张量 | 取奇数 `C` 张相邻 `x–y` 切片，每张裁成 `224×224`；标签为中心切片中全部模拟器械的联合二值分割；体数据推理时逐切片滑窗并堆叠输出。 |
| 结构 | 与 A-DTE 相近的二维 U-Net：`C` 输入通道、单张中心切片输出，最终激活为 sigmoid。属于 2.5D，而不是 3D 卷积。 |
| 训练 | 输入体在送入网络前归一到零均值、单位方差；soft Dice，原文式 (4) 对整个 batch 的像素求和，分子与分母各加 1；Adam `lr=1e-4, β1=0.9, β2=0.999`；batch size 16；推理概率四舍五入为 0/1（阈值 0.5）。 |
| 原文消融 | `C=1,3,5`；表 2 中 `C=5` 的验证 Dice 为 `0.794±0.065`，三者中最高。正式基线选 `C=5`，并保留 `C=1,3` 以复核消融。 |

### 2.4 A 的论文验证与边界

- 完整介入引导图还将器械分割叠加到利用历史投影更新的患者体上；本项目只实现用户需要的**器械重建分支**，不把患者时序体积更新当作神经网络的一部分。
- 原文做过二投影、三投影消融。三投影实验保持作者定义的 `180°` 总角度范围；缩小间隔到 `30°/22.5°` 是**四投影**实验。二者不能合并表述为已经验证了三投影 0–60°。
- 原文体模组合测试把体模有无器械投影的差值叠加到独立患者投影，再运行 DTE；该验证设计与 DTR 的理想投影训练条件不同，须分别记录。

## 3. 原文 B：Vöth 等（2022）

### 3.1 原文数据和几何

1. **主几何（原文明确）：**三幅投影由相隔 `60°` 的成像通道同时获取，如 `0°/60°/120°`。每个通道由点源和平板探测器构成：探测器 `1024×1024`、像素间距 `0.3 mm`、源探距 `1100 mm`、源到等中心 `600 mm`。DTR 使用 `256³` 网格、体素 `0.6 mm`；每个模拟场景存储其中的 `128³` 块并以 `128³` 块训练。
2. **DTE 数据（原文明确）：**12,000 幅模拟导丝投影、12,000 幅模拟支架投影，与九名患者的 2,751 幅不含器械的临床 CBCT 投影在线组合；模拟不同程度的模糊、噪声、散射。不要把这组数量混同于 DTR 的场景数。
3. **DTR 数据（原文明确）：**40,000 个场景，每个场景一个支架加一或两根导丝，训练/验证 `70/30`。导丝为随机游走样条中心线附近的弯曲圆柱；支架由沿中心轴堆叠的圆柱形杆件段组成，再沿样条弯曲；直径、段高、波纹数、杆件厚度、杆件样式、段数、轴向偏移与弯曲均随机变化，模拟主动脉支架直径 `10–30 mm`。图像块做 z 轴翻转和绕 z 轴 `90°` 整数倍旋转增强。
4. **DTR 输入标签（原文明确）：**模型三角网格的二值体素化为真值；先正投影，再把三幅投影**分别反投影到三个体通道**。为模拟 DTE 错误，在 DTR 的训练投影中人工加入假阳性与假阴性。

### 3.2 B-DTE：二维器械提取网络

| 项目 | 原文明确的实现 |
| --- | --- |
| 任务 | 单幅投影 → 导丝与支架的逐像素衰减线积分值。 |
| 结构 | 2D U-Net 类；编码/解码分辨率阶段各做两次 `3×3 Conv → BatchNorm → ReLU`；`n=1…7` 阶段通道数 `32×2^n`，即 `64,128,256,512,1024,2048,4096`；`2×2` max pool，最近邻上采样再接 `3×3` 卷积。原文未报告 dropout。 |
| 训练 | `384×384` 输入/目标块；MAE；Adam `lr=1e-5, β1=0.9, β2=0.999`；batch size 24；200 epoch，每个 epoch 16,000 训练对和 4,000 验证对。 |

### 3.3 B-DTR：三通道三维重建网络

| 项目 | 原文明确的实现 |
| --- | --- |
| 张量 | 三幅 DTE 输出各自反投影到一个体通道；输入 `[B,3,128,128,128]`，目标是同区域支架与导丝的**联合**单通道二值体素分割。**不先把三个视角求和，也不采用 A 的 FDK 单体输入。** |
| 结构 | 3D U-Net 类；每阶段两次 `3×3×3 Conv → BatchNorm → ReLU`；`n=1…5` 通道数 `8×2^n`，即 `16,32,64,128,256`；`2×2×2` max pool，最近邻上采样再接 `3×3×3` 卷积。 |
| 训练 | soft Dice + Laplace 平滑；Adam `lr=1e-4, β1=0.9, β2=0.999`；batch size 8；150 epoch，每个 epoch 16,000 训练对和 4,000 验证对。 |
| 原文消融 | 单通道版本把三个反投影体相加再送入另行训练的 DTR；论文验证 Dice 为三通道 `77.5%`、单通道 `72.3%`。正式基线用三通道，另留单通道消融。 |

### 3.4 B 的论文验证与边界

- 实测实验从精细角度采样的静态体模扫描中回选三幅目标投影；真值由该密集扫描的 FDK 体阈值化获得。三种场景是两根导丝、单个支架、支架内一根导丝。论文方法假设三通道同时曝光；这里的回选投影是其体模验证方式。
- 论文用重建骨架与真值骨架的**两个方向的平均欧氏距离**作为实测主指标，原因是杆件通常只有 `1–3` 个体素粗，Dice 对表面阈值非常敏感。
- 原文使用 TensorFlow 2.5.0；PyTorch 移植需检查 `padding`、BN 动量与 epsilon、最近邻插值坐标、卷积初始化、Dice 归约、`channels_last`/`channels_first` 轴顺序等语义。该列表是移植风险，**不是原文给出的超参数值**。
- 论文报告的运行时间是在 RTX 3090、TensorFlow 2.5.0、混合精度、图执行且数据已在 GPU 上的条件下测得；PyTorch 移植的耗时须实测并附硬件与运行条件，不能直接沿用论文的毫秒数。

## 4. 0–60° 静态实验：与论文原法严格分开

1. 先保留两个**原文配置**：A 为四幅相邻 `45°`，B 为三幅相邻 `60°`。它们用于架构和数据管线的复现自检。
2. 用户实验另设 **A-adapted-3view** 与 **B-adapted-3view**，两者均接收三幅静态投影。角度是参数；若用户尚未指定具体角度，预设 `[0°,30°,60°]` 仅用于实验配置，不写成论文原角度。
3. 适配 A 时，仅把四投影 FDK 输入改为三投影 FDK 输入，保留其 DTE 和 `C` 切片 2.5D DTR；适配 B 时保留三通道反投影和 3D DTR。两者的训练输入均按新角度重新生成并重新训练；不能沿用论文原角度的 DTR 权重直接比较。
4. 为保持论文训练方法，A 的 DTR 继续使用**理想器械投影**训练，B 的 DTR 继续使用**注入 DTE 式错误的投影**训练；两者推理时都运行各自 DTE。这一区别必须保留并在结果报告中说明。
5. 保留论文原本的多器械训练目标：A 包含导丝/支架/线圈，B 包含支架/导丝；只在测试中选出**仅含支架**的病例计算支架指标。若决定只用支架训练，那是另一个明确标注的消融，不是原法。
6. 按实体三维模型划分训练、验证和测试，防止不同投影视角的数据泄漏。两种方法在用户场景上使用同一批测试支架、同一投影与同一三维真值；内部体素网格可按各文原法保留，评分前对齐到同一物理坐标网格。
7. 论文网络输出是器械杆件分割。若用户的“轮廓”指外包络或二维投影外边界，需要另给真值与定义；本实验先以支架杆件三维掩膜和论文相同类型的指标作为对比对象。

## 5. 实现契约与验收

### 5.1 PyTorch 接口

- `A_DTE`、`B_DTE`：单幅投影 `[B,1,H,W]` → 连续器械投影 `[B,1,H,W]`。
- `A_DTR`：`[B,C,224,224]` → 中心切片 `[B,1,224,224]`；`C` 为奇数，论文消融配置为 1、3、5。
- `B_DTR`：`[B,3,128,128,128]` → 单通道三维分割 `[B,1,128,128,128]`。单通道消融另建配置/模型，不共享三通道权重。
- `A_FDK` 与 `B_per_view_backprojection` 必须使用真实标定几何与物理体素坐标；应分别测试，不能共用一个“笼统反投影”替代不同方法。

### 5.2 验收条件

1. 四个网络的前向张量形状、梯度传播、损失值有限、空/非空目标行为可验证。
2. 用三维点、直线与支架网格做正投影—反投影检查，核对三视角顺序、像素到毫米尺度、坐标手性和目标位置。
3. 原文配置与目标适配配置分开保存；配置清楚记录随机种子、角度、几何、强度归一化、训练模型类别及体素间距。
4. A 验证 `C=1/3/5` 的独立训练配置；B 验证三通道与单通道是分别训练的模型。论文数值仅作核对锚点：A 表 2 的 `C=5` 验证 Dice 为 `0.794±0.065`；B 三通道 DTR 的训练/验证 Dice 为 `78.2%/77.5%`。若没有原始数据，仅能验证架构与处理流程，不能声称重现这些精度。
5. 目标实验报告 Dice、precision、recall、骨架双向平均距离（mm），并单独列出原论文数值作参照。外包络指标仅在给出其真值定义后加入。

## 8. 对照修订记录

- **初次修改：**将原 Spec 的“两种方法均用 PyTorch 等价改写并直接按 0–60° 训练”改为“原文配置 + 明确标注的任务适配”；按用户要求仍统一用 PyTorch。补齐 A-DTR 的理想投影训练条件和 B-DTR 的投影错误增强。
- **第一轮复核：**逐项核对 A 的 §2.2–2.6、§3.2–3.5 与 B 的 §2.1–2.4。修正 A 投影翻转的措辞，避免推断原文未列出的组合；明确 B 的三视角同时获取与其静态体模回选投影的区别；明确 B 每场景保存 `128³` 块。
- **第二轮复核：**对照 A 的图 1、表 2 和 B 的图 1、表 1，再查网络目标、消融和评价定义。明确两文均预测多种器械的**联合二值分割**，支架专属指标只在纯支架测试场景中计算；增加论文精度的核对锚点与 B 的运行时间条件，避免把原文计时当作 PyTorch 移植的性能保证。
