# 从二维投影和三维真值生成训练样本

入口：`python -m stent_repro.preprocess`。它将 TIFF 或 NumPy 输入转换为现有训练入口可读取的 DTE 和 DTR 样本，并将几何、随机种子、增强参数、清单哈希和方法配置写入 `provenance.json`。生成的是**CPU 参考实现及替代模拟样本**，不是论文原始数据或数值复现。

## 必须先明确输入和几何

三维真值必须是器械联合二值掩膜（0/1），数组为 `[z,y,x]`，提供单位为毫米的 `spacing_mm`、首个体素中心的 `origin_mm`（均按 `[x,y,z]`）和 `direction`。当前只支持与世界坐标轴平行的单位方向矩阵；旋转体必须先在外部按已知物理坐标重采样。等中心为世界坐标 `(0,0,0)`。

二维输入为灰度投影，单张 `[v,u]`、多页 TIFF `[view,v,u]` 或带 `sequence.json` 的 TIFF 序列目录。投影顺序必须与实际角度一一对应。若 TIFF 没有配套元数据，可以像下面的示例直接在清单中提供；也可用 [数据读写](数据读写.md) 的旁车元数据。投影应当经过几何校正；本实现假设理想圆轨迹、平板探测器、等间距正方形像素、主射线经过等中心，无探测器偏置或倾斜。0° 时射线源为 `(0,-SID,0)`，探测器 u 正方向为 `+x`、v 正方向为 `+z`，角度绕 `+z` 转动。请先将实际系统角度和坐标转换为这一约定；程序无法从灰度图验证真实校准或配准。

每个样本必须声明 `projection_role`：

- `patient_without_tool`：二维投影不含器械；程序将三维掩膜模拟出的器械连续线积分加入背景，并模拟量子噪声、模糊及可选 B 散射。
- `measured_with_tool`：二维投影已含器械；必须确认二维投影与三维真值在已给几何中配准，并填写 `registration_confirmed: true`。程序直接用该投影作为 DTE 输入，不再次叠加器械；DTE 标签是以单一衰减系数从真值模拟的投影，是近似标签。程序无法代替实际配准检查。

二维数据可以声明 `line_integral`，或声明 `detector_intensity` 并显式提供标量 `flat_field`、`dark_field` 与 `transmission_floor`。后者按 `-log(clip((I-dark)/(flat-dark), floor, 1))` 转换；它不是空间变化的平暗场校正，裁剪会损失超出范围的强度信息。若需要逐像素平暗场，应先在外部完成校准。不能把任意窗宽窗位显示图直接视为线积分或探测器原始强度。

## 输入清单

以下仅展示结构；路径相对清单文件，`model_ids` 和 `patient_id` 使用真实来源标识，训练与验证不可共享。每个病例的背景投影角度可以与 DTR 角度不同，例如前者使用 17 个相邻 10° 视角，后者使用 `[0,30,60]`。

```json
{"cases": [
  {
    "id": "train_case", "split": "train", "model_ids": ["stent01"], "patient_id": "patient01",
    "truth": "train_mask.tif", "truth_grid": {"spacing_mm": [1,1,1], "origin_mm": [-7.5,-7.5,-7.5], "direction": [[1,0,0],[0,1,0],[0,0,1]]},
    "background": "train_projections.tif", "background_units": "detector_intensity", "background_angles_deg": [0,30,60],
    "projection_role": "patient_without_tool", "angles_deg": [0,30,60]
  },
  {
    "id": "validation_case", "split": "validation", "model_ids": ["stent02"], "patient_id": "patient02",
    "truth": "validation_mask.tif", "truth_grid": {"spacing_mm": [1,1,1], "origin_mm": [-7.5,-7.5,-7.5], "direction": [[1,0,0],[0,1,0],[0,0,1]]},
    "background": "validation_projections.tif", "background_units": "detector_intensity", "background_angles_deg": [0,30,60],
    "projection_role": "patient_without_tool", "angles_deg": [0,30,60]
  }
]}
```

对于已含器械的实测投影，将 `projection_role` 改为 `measured_with_tool` 并增加 `"registration_confirmed": true`。清单里的 `angles_deg` 控制 DTR 配置，`background_angles_deg` 控制 DTE 投影顺序。两者可以分别提供；如 TIFF 旁车已有对应字段，不应冲突。

## 参数文件和运行

将下列内容保存为 `params.json`。**这些仅是可运行的小体模示例值，不是设备标定或论文参数。**必须按真实系统替换，包括几何、检测器形状、强度平暗场、器械有效衰减、噪声与增强参数。`detector_shape` 顺序是 `[height,width]`，`dtr_crop_shape` 是 `[z,y,x]`；后者可省略，省略时保留完整真值体。裁剪按体中心执行并更新物理原点，不能超过输入体。原论文 A 的 DTR 需要 `224×224` 切片，B 需要 `128³` 块；下例的 16³ 仅用于小体模。

```json
{
  "sdd_mm": 200, "sid_mm": 100, "pixel_size_mm": 2, "detector_shape": [16,16],
  "attenuation_per_mm": 0.1, "integration_step_mm": 0.5,
  "flat_field": 1000, "dark_field": 10, "transmission_floor": 0.001,
  "photons": 100000, "blur_sigma_px": 1.0, "scatter_fraction": 0,
  "false_negative_rate": 0.05, "false_positive_rate": 0.001, "false_positive_scale": 0.2,
  "patch_size": 16, "min_background": 0.01, "dtr_crop_shape": [16,16,16], "seed": 42
}
```

- `attenuation_per_mm` 是用户选择的单一有效衰减系数，不是论文的多色能谱；`integration_step_mm` 控制射线积分步长，越小越慢。
- `photons` 是 Poisson 入射计数；`blur_sigma_px` 是模糊标准差上限，逐样本在 0 至该值间抽样；训练样本的器械投影可随机沿 x、y 翻转，目标随之翻转。A 不允许非零 `scatter_fraction`；B 的散射只是常数比例的简化替代。
- B 假阴性是随机抑制真实投影像素，假阳性是在零投影像素插入幅度受限的值，三视角分别处理；其概率及幅度为可审查的替代模型，不是论文公开的唯一算法。DTR 验证输入也以固定种子预生成，训练阶段不会再次改变其标签；B 训练还对体数据做同步旋转/翻转。
- DTE 图像块按背景最小平均线积分筛选、同位置裁剪；每个背景视角生成一对样本。默认预先生成；训练 DTE 时可加 `--online-dte`，对已保存的背景块和器械投影块在每次读取时重新采样噪声、模糊和翻转。块位置及背景/器械配对仍然固定，并不重新抽取患者块或器械模型。验证输入保持固定。程序不会自动产生论文的 16,000/4,000 对或 40,000 个场景。

在 PowerShell 中：

```powershell
$env:PYTHONPATH = 'src'
python -m stent_repro.preprocess --method A --profile A-adapted-3view --manifest raw_cases.json --params params.json --output outputs/prepared_a
python -m stent_repro.training --method A --stage dte --config configs/eulig2021/adapted_3view_0_30_60.yaml --manifest outputs/prepared_a/dte.json --output outputs/train_a_dte --mode prepared-surrogate --online-dte --epochs 10 --batch-size 2 --device cpu
python -m stent_repro.training --method A --stage dtr --config configs/eulig2021/adapted_3view_0_30_60.yaml --manifest outputs/prepared_a/dtr.json --output outputs/train_a_dtr --mode prepared-surrogate --epochs 10 --batch-size 2 --slice-channels 5 --device cpu
```

B 使用 `--method B --profile B-adapted-3view` 单独生成，在训练时将配置改为 `configs/voth2022/adapted_3view_0_30_60.yaml`。B-DTR 维持三个分别反投影的通道；单通道消融须另用对应 ablation 配置和单独生成目录。训练参数与恢复方式见 [训练流程](训练流程.md)。参数示例中的 10 epoch、batch 2 和 CPU 仅演示调用，不能称为论文严格配置。

生成目录必须为空。输出 `dte.json`、`dtr.json`、各样本 NPZ 和 `provenance.json`；训练会检查自动生成清单的哈希并把来源记录进检查点，但不会对全部数据文件做哈希。

## 几何算法和验证边界

前向投影使用有限步长、三线性插值的射线积分。A 的 FDK 使用探测器余弦权重、绝对频率 ramp、平方距离加权反投影和有限角域梯形角度权重；没有 Parker 加权。完整圆周小圆柱体模检查过中心线积分尺度和中心重建值，点投影与角度/通道顺序有测试。三、四投影的有限角重建存在不可消除的欠采样伪影；该小体模验证不等于对真实系统、器械尺度或论文实现的全面验证。B 是独立的逐视角反投影，不把三通道先相加。

所有前处理目前是 CPU 参考版本，原论文探测器与网格尺寸可能需要很长时间及较多内存；尚无 CUDA 生产后端、多色谱、随机三维器械模型生成、真实系统校准或论文数值验证。本机 CUDA 不可用。正式训练前还须真实硬件显存预检和更全面的物理体模验证；`strict` 模式继续禁用。
