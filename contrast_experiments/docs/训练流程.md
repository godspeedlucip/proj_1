# 预生成样本的训练流程

2026-11-16：新增独立的 [v2 双基线工作流](双基线工作流.md)，包含完整推理/评价、在线源池和训练中更新的 A-DTE 归一化。下文仍描述旧 `stent_repro.training` 入口，其冻结统计与 prepared-surrogate 语义保留。

当前实现可训练两篇方法的 DTE 和 DTR，但使用事先准备好的监督样本，运行标签为 `prepared-surrogate`。它**不是论文原始数据和原始模拟流程的严格复现**。可以通过 [投影与真值前处理](投影与真值前处理.md) 用 CPU 参考实现生成 FDK、逐视角反投影、DTE 合成及 B 错误增强样本；它们使用单色和简化错误模型，尚未完成真实系统验证及论文的完整在线采样。对于预处理生成的无器械背景样本，DTE 可加 `--online-dte` 在线重采样噪声、模糊和翻转；数据块及组合仍固定。`--mode strict` 会明确拒绝运行。

本机目前是 CPU 版 PyTorch；B-DTE 的 4096 通道网络非常大。正式训练前需要 CUDA 版 PyTorch、完整尺寸实测显存、真实数据和必要的几何验证；不要仅因小样本测试通过就启动全尺寸训练。

## 样本清单

清单为 UTF-8 JSON，文件路径相对于清单文件。各样本必须填写真实实体 `model_ids`，同一模型不能跨 train、validation、test。DTE 如有 `patient_id` 也应填写，程序会拒绝该患者跨数据集；没有提供患者 ID 时无法检出此类泄漏。训练和验证至少各有一项；`test` 只保留，不参与训练或验证。

DTE 输入为单张含背景投影，标签为同尺寸的连续器械线积分，不是二值图。示例：

```json
{"samples": [
  {"id":"tr1", "split":"train", "model_ids":["tool1"], "patient_id":"patient1", "input":"data/input1.tif", "target":"data/target1.tif"},
  {"id":"val1", "split":"validation", "model_ids":["tool2"], "patient_id":"patient2", "input":"data/input2.tif", "target":"data/target2.tif"}
]}
```

A-DTR 输入是**理想无噪器械投影重建出的单个 FDK 体**，不是逐投影通道，也不是 DTE 的噪声输出。标签为同网格器械联合二值体；一体会按中心层展开成训练样本。示例：

```json
{"samples": [
  {"id":"tr1", "split":"train", "model_ids":["tool1"], "input":"data/fdk1.tif", "target":"data/mask1.tif", "source":"ideal_tool_fdk", "angles_deg":[0,45,90,135]},
  {"id":"val1", "split":"validation", "model_ids":["tool2"], "input":"data/fdk2.tif", "target":"data/mask2.tif", "source":"ideal_tool_fdk", "angles_deg":[10,55,100,145]}
]}
```

B-DTR 为每个场景提供三个已注入模拟 DTE 错误、按角度顺序分别反投影的体及同网格联合二值标签；`input` 和 `angles_deg` 必须逐项对应。程序不会通过文件内容验证声明的来源或视角顺序，准备数据时必须自行核对。单通道消融使用相同的三个输入，在入口求和，另建模型和输出目录。

```json
{"samples": [
  {"id":"tr1", "split":"train", "model_ids":["stent1","wire1"], "input":["data/bp1_0.tif","data/bp1_30.tif","data/bp1_60.tif"], "target":"data/mask1.tif", "source":"error_augmented_per_view_backprojection", "angles_deg":[0,30,60]},
  {"id":"val1", "split":"validation", "model_ids":["stent2","wire2"], "input":["data/bp2_0.tif","data/bp2_30.tif","data/bp2_60.tif"], "target":"data/mask2.tif", "source":"error_augmented_per_view_backprojection", "angles_deg":[0,30,60]}
]}
```

输入/标签支持 `.tif/.tiff`、`.npy`、本项目的 `.npz`。文件维度及元数据见 [数据读写](数据读写.md)。如果任何 DTR 输入提供 spacing、origin 或 direction，相应字段必须在所有输入及标签中提供且一致；完全缺失时程序不能验证物理配准。当前实现不自动重采样。DTE 每对必须尺寸一致；DTR 标签必须是 0/1。B 的通道和标签体必须形状一致。运行实际网络时还须满足网络池化层的尺寸要求，批内样本形状必须一致。

## 运行

在项目根目录执行 PowerShell：

```powershell
$env:PYTHONPATH = 'src'
python -m stent_repro.training --method A --stage dte --config configs/eulig2021/original_4view.yaml --manifest data/a_dte.json --output outputs/a_dte --mode prepared-surrogate --epochs 10 --device cpu
python -m stent_repro.training --method A --stage dtr --config configs/eulig2021/adapted_3view_0_30_60.yaml --manifest data/a_dtr.json --output outputs/a_dtr_c5 --mode prepared-surrogate --epochs 10 --slice-channels 5 --device cpu
python -m stent_repro.training --method B --stage dte --config configs/voth2022/original_3view_60step.yaml --manifest data/b_dte.json --output outputs/b_dte --mode prepared-surrogate --epochs 200 --device cuda
python -m stent_repro.training --method B --stage dtr --config configs/voth2022/adapted_3view_0_30_60.yaml --manifest data/b_dtr.json --output outputs/b_dtr --mode prepared-surrogate --epochs 150 --device cuda
```

A 的论文未给 epoch，请自行指定；上面的 10 仅为命令示例。batch 和学习率默认读取配置；可用 `--batch-size` 指定替代实验的批量，不能把修改后的配置宣称为论文原设置。B 单通道消融使用 `configs/voth2022/one_channel_ablation.yaml --input-channels 1`，并使用单独的输出目录。A 的 C=1、3、5 使用 `--slice-channels` 分别训练并保存。

A-DTE 根据训练输入计算全局均值和标准差并冻结用于训练和验证（启用在线增强时，统计量来自训练集的一次随机采样），标签不归一化；A-DTR 每个输入体单独做零均值单位方差。B-DTR 的训练样本随机做 z 翻转和绕 z 轴的 90° 倍数旋转，输入通道和标签同步，验证集不增强。DTE 用 MAE，DTR 用各自 Dice 损失，优化器均为 Adam。每个 epoch 遍历清单一次；B 论文中的在线采样 16000/4000 对尚未实现，清单大小不会自动改成这些数量。所有数据处理只针对预生成样本，实际来源需自行负责。

## 产物及恢复

输出目录包含 `last.pt`、按验证损失选出的 `best.pt` 和 `metrics.json`。检查点包含模型、优化器、epoch、训练统计、随机数状态、配置、清单 SHA-256 和数据规模。已有 `last.pt` 的目录默认拒绝覆盖；使用相同参数并指定 `--resume outputs/.../last.pt` 可继续，`--epochs` 是最终总 epoch，须大于已完成 epoch。恢复会检查配置、清单文件哈希和模型形状，但**不对每个数据文件重新计算哈希**，训练期间不要修改清单引用的数据文件。只加载可信来源的检查点。

这些文件记录的是替代流程的损失，不是论文体模 Dice 或骨架距离。完整推理、测量验证及论文数值复现仍未完成。
