# 双基线复现优化与静态三投影对比 Spec

日期：2026-11-16  
状态：用户已授权制定 Plan 并实施；本文列出设计要求，不表示所有实验已经完成。  
适用对象：Eulig 2021（A）和 Vöth 2022（B）的器械重建分支。  
关联文档：[原始规格](../../../SPEC_静态三投影支架重建双基线.md)、[现有进度](../../../复现进度.md)。

## 1. 目标和推荐方案

把现有“网络模块与预生成样本训练程序”补齐为可训练、可推理、可公平评价的两套对比基线。先解决方法忠实度和实验完整性，再开展提高精度或速度的独立改进。主要交付是可追溯的实验结果，不以运行成功或测试通过替代精度验证。

采用两条实验线。

- **论文参考线**：保留各论文的视角、网络、训练目标和数据要求，用于检查方法实现和复核原文实验。数据或未公开细节存在替代时，标为方法复现及其具体偏差。
- **课题对比线**：A、B 使用同一组静态三投影和测试支架，默认角度为 `[0,30,60]°`，分别重新训练 DTR，评价三维支架杆件分割。该默认值沿用既有规格，并非用户新确认的设备角度。

两条线的结果分别报告。不同论文原生数据、视角和体素尺寸上的分数不能直接组成优劣排名。

课题线的 A/B 均使用课题设备的同一套实际投影标定；“保留原生网格”仅指各方法的重建网格选择，不意味着用不同扫描器几何解释同一批测量投影。

### 1.1 方案取舍

| 方案 | 能回答的问题 | 代价与限制 | 本 Spec 的选择 |
| --- | --- | --- | --- |
| 只补原论文条件 | 是否覆盖原文方法及验证流程 | 原始模型、患者投影缺失；不能直接回答本课题 0–60° 场景 | 保留为参考线 |
| 只统一到课题数据 | 哪套适配流程适合当前任务 | 容易失去原文方法边界，难解释偏差来源 | 不单独采用 |
| 参考线和课题线并行管理 | 方法忠实度与课题实际效果 | 需要明确配置、数据和报告归属 | **推荐，作为本草案的设计选择** |

用户已授权依据此设计制定 Plan 并实施；正式实验仍取决于数据、标定和实际可用训练资源。

### 1.2 范围

必须覆盖 DTE、几何变换、DTR、训练、推理、评价、必要消融与运行记录。输出对象是器械联合二值分割；主测试集为纯支架病例，才可将输出解释为支架分割。

本阶段不增加 Transformer、注意力模块或新的主损失；不实现患者动态背景更新；不把杆件分割改为外包络分割。外包络需要单独的任务定义、真值和评价协议。上述增强可在基线验收后作为新实验提出。

## 3. 必须保留的方法差异

| 项目 | A | B |
| --- | --- | --- |
| 参考视角 | 四幅，相邻 45°，训练有随机起始角 | 三幅，相邻 60° |
| DTE 输出 | 连续器械衰减线积分 | 连续器械衰减线积分 |
| 几何变换 | 多视角滤波反投影形成单个 FDK 体 | 每幅投影分别反投影，保留三个体通道 |
| DTR | 2D 卷积，相邻 C 张切片输入，预测中心切片 | 3D 卷积，三通道体输入，预测三维分割 |
| DTR 训练投影 | 理想、无噪声、仅器械 | 模拟器械投影，并注入 DTE 式错误 |
| 参考训练器械 | 支架、导丝、线圈 | 支架、导丝 |
| 核心消融 | C=1、3、5 | 三通道与求和后的单通道，分别训练 |

课题主比较继续保留这些方法差异。因此，它比较的是两套适配流程；不能将差值全部归因于 2.5D 与 3D 网络。若研究目标是单独比较网络结构，需要另设相同训练数据及前处理控制实验。

## 4. 配置和数据契约

### 4.1 配置必须控制实际执行

建立一个解析后的 `resolved_config`，作为数据生成、训练、推理、评价的共同输入。旧 YAML 可以迁移，但不能仅将字段写入日志而不执行。

必须包含以下分组。

| 分组 | 关键内容 |
| --- | --- |
| 实验身份 | 方法、阶段、参考/课题线、视角列表、随机种子、数据版本 |
| 网络 | 架构版本、编码/解码阶段、输入通道、输出激活、BN、初始化、损失定义 |
| 几何 | 每视角标定、探测器尺寸、像素尺寸、体素网格、世界坐标系、强度单位 |
| 数据生成 | 模型分布、材质/谱模型、背景来源、噪声/模糊/散射及错误增强 |
| 训练 | 真正的 batch size、学习率、epoch、每轮采样数量、裁块与归一化策略 |
| 推理与评价 | padding、分块策略、输出阈值、评价网格、ROI、骨架算法、计时条件 |
| 来源 | 原文位置、实现选择、任务适配、资源适配与未解决项 |

数组约定固定为体数据 `[z,y,x]`、投影 `[view,v,u]`、探测器尺寸 `[height,width]`；spacing 和 origin 为世界坐标 `[x,y,z]`，单位 mm。旋转网格必须支持完整坐标变换，或明确拒绝并要求预先重采样。

命令行覆盖必须写入最终配置并参与配置哈希。未知字段、未消费字段、几何冲突、视角与通道顺序不一致必须报错。实际设备几何尚未提供时，示例几何只用于 G0，不可启动正式 G1 测量实验。

### 4.2 数据划分与来源

1. 先划分实体模型和患者/扫描来源，再生成投影与在线组合。一个实体及其旋转、形变、噪声变体不得跨集合；同一次扫描的不同投影不得跨集合。
2. 区分实体身份 `entity_id` 与基础设计 `design_family_id`。主测试防止实体泄漏；未见过的支架设计家族作为额外泛化测试，不默认把所有同类型支架视为同一实体。
3. 多器械场景共享实体时，按共享关系整体分组。不得为凑齐比例拆散组；报告实际数量和比例。
4. 课题线建议训练/验证/测试按独立实体约 70/15/15 划分，属于本项目选择；B 参考线保留原文场景训练/验证 70/30。测试病例数量随数据盘点冻结，不凭现有小样本推断充分统计效能。
5. 保存清单及所有被引用数据的内容哈希、单位、标定版本和处理历史。测试集不得用于调整阈值、错误强度、epoch、架构或挑选训练种子。
6. 区分无器械背景、含器械实测投影和模拟器械投影。含器械实测图不得再次叠加器械；从其真值模拟的 DTE 标签只能标为近似标签。

## 5. 网络忠实度与移植

### 5.1 A 的阶段数

列为优先核查项，不将“再加一层”预设为修复答案。实施时输出逐层表，包括分辨率、通道数、下采样次数、瓶颈计数、跳连、解码阶段和参数量，与原文 §2.4.2 对照。

若可获得作者代码或明确图示，按可核验证据确定主版本。若仍无法唯一确定，保留当前 `legacy-4enc-3dec`，另记录常规四级下采样解释的候选版本，分别命名、保存权重；主版本选择必须在课题验证阶段结束前固定，不得依据测试分数挑选。候选版本属于有来源说明的解释，不能改写为“原文明确”。

A-DTE 保留 Conv→BN→SpatialDropout(0.2)→ReLU、He 初始化及 ReLU 输出；A-DTR 保留 2.5D 输入、sigmoid 和原文 batch 全局求和的 soft Dice。

### 5.2 B 的 PyTorch 移植

保留 DTE 七级通道 `64,128,256,512,1024,2048,4096`，DTR 五级通道 `16,32,64,128,256`，并输出完整层表。

显式配置 BN epsilon、移动统计更新公式、卷积 bias/初始化、padding、插值方式、输出激活、Dice 平滑与归约。不要把 PyTorch 默认值或 TensorFlow 常见默认值直接认定为作者实际设置。

有作者实现时，用同权重、小输入逐层对齐；没有作者实现时，可建立明确指定语义的跨框架探针，但只能验证所选移植规则。B 默认 ReLU/sigmoid、平滑常数 1、batch 全局 Dice 可作为项目选择保留，需记录其非原文明确性质。

### 5.3 资源限制

正式运行前实测完整输入、真实 batch 的前向、反向、优化器状态和峰值显存。meta、参数量估计和小图测试不能代替该检查。

优先评估缓存、混合精度及激活重计算；采用后记录数值偏差、随机数与 BN 状态行为。缩通道、改 patch、减 batch 或改归一化均建立独立资源适配版本。梯度累积不自动等价于原 batch，尤其存在 BatchNorm 时。

资源预检失败时，输出具体失败配置及后续所需硬件；继续可完成的 G0 工作。不得把缩小后的配置记为论文原设置。

## 6. 数据生成与训练优化

### 6.1 先构建可追溯的数据，再扩大规模

先用少量可验证的模型完成全链路，再扩大到参考规模或课题数据规模。模型生成器输出三角网格、参数、实体身份、随机种子和物理单位。体素化记录采样规则；细杆件应做分辨率/采样收敛检查，避免在生成标签时消失。

| 数据 | 参考线要求 | 缺失资源时的处理 |
| --- | --- | --- |
| A 模型 | 600 个，三类各 200；支架八种基础设计、NURBS 形变及原文尺寸范围 | 八种源模型未获得时，使用可追溯替代设计并标注，不宣称重建了作者模型集 |
| A 投影 | 原文多色模拟、铁的密度范围；DTE 每模型 17 个相邻 10° 视角 | 谱、材料与探测器响应须有来源；无法获得时保留单色替代标签 |
| B 模型 | 支架杆件段堆叠后沿样条弯曲；随机尺寸/样式；每场景一支架加一或两根导丝，共 40,000 场景 | 原文未给出的分布显式参数化，并做分布记录；不臆造为作者值 |
| 患者背景 | A 原文扫描分组；B 原文九名患者共 2,751 幅背景投影 | 使用合法、可追溯的独立背景，声明患者及设备差异 |

A 理想 DTR 投影不注入 DTE 错误。B 错误增强保留独立像素抑制/插入作为可追溯的初始方案；连续缺失杆件或连通假阳性等更贴近真实 DTE 的模型作为独立消融，并仅利用训练/验证数据校准。

### 6.2 在线 DTE 采样

每次读取重新抽取训练背景图及位置、器械模型/投影块及放置位置，生成 `384×384` 训练对；过滤低衰减背景，保留连续、干净的器械目标。不能仅在固定配对上刷新噪声就视为完整在线采样。

Poisson 入射计数、模糊和 B 的散射参数从已声明分布采样；A 的模糊上限依原文为 1.4 px，原文未给出的计数范围必须作为实现选择。光子计数到线积分的变换、模糊作用域和散射模型写入处理记录。

A-DTE 使用在线运行均值/方差，只由训练输入更新；验证和推理冻结统计，不接触测试数据。采用样本更新还是 batch 更新、更新前后应用的顺序须固定并保存；本项目建议按训练 batch 更新后标准化，作为实现选择。恢复训练必须恢复累计数量、均值和二阶统计。

### 6.3 DTR 采样

- A：从理想 FDK 体随机选择中心层与 xy 位置，裁 `C×224×224`，标签为同位置中心层。主配置 C=5，C=1/3 独立训练。默认先对完整输入体标准化后裁块，属于实现选择。训练优先抽取足够上下文的中心层，推理边缘用明确的复制 padding。
- B：参考线按 `256³ / 0.6 mm` 场景生成并保存 `128³` 块；每次训练读取对三通道和标签同步做 z 翻转、绕 z 的 90° 整数倍旋转。块位置选择与是否保留空块需固定并记录，不能假定论文只选中心块或只选非空块。
- 不默认添加前景过采样、额外数据清洗或难样本挖掘。若使用，分别记录其采样分布，避免悄悄改变论文训练条件。

### 6.4 每轮规模与模型选择

B 的 DTE 为 200 epoch、batch 24、lr=1e-5；DTR 为 150 epoch、batch 8、lr=1e-4；两者每轮实际采样 16,000 个训练对和 4,000 个验证对。训练采样以固定种子控制，允许有放回，并记录实际样本数、重复次数、batch 数及优化器步数。尾批不丢弃，不能因为 16,000 不能整除 24 而静默改变每轮样本数。

A 保留原文学习率与 batch；epoch 及每轮数量原文未给出，配置必须显式提供。建议用验证集确定固定训练预算，再为所有重复实验冻结；不得把 B 的 150/200 epoch 自动归给 A。

在线验证随机配对按 `(run_seed, epoch, sample_index)` 重放，另建立固定验证面板用于选择课题线检查点。参考 B 至少报告第 150/200 epoch 的对应结果；课题线按预先定义的固定验证指标选 best，同时保留 last。训练 loss、二值 Dice 与体模评价分别命名，不能以 `1-loss` 冒充论文 Dice。

DTE 与 DTR 分别监督训练，推理时组合。课题线默认 DTE 按固定验证面板 MAE 最低选择，DTR 按固定验证病例的二值 Dice 宏平均最高选择；相同分数保留较早 epoch。面板病例清单、大小和评价频率在先导实验后冻结，不参与测试集调参。DTR 检查点评价保留各方法规定的训练输入来源；另行报告使用真实 DTE 输出的完整流程验证。

检查点包含网络/优化器、数据采样器、归一化、Python/NumPy/PyTorch/设备随机数状态和 AMP 状态（若使用）。恢复验证覆盖样本序列与后续训练结果，不只核对 epoch。

## 7. 几何验证与完整推理

### 7.1 几何

将 CPU 参考后端与可选加速后端分开，统一物理坐标接口。不能通过把 A、B 共用一个无差别的反投影函数来简化两种方法。

几何验收至少包括解析点/直线投影、偏轴圆柱、倾斜细杆和支架网格；覆盖视角顺序、坐标手性、探测器像素中心、体素中心、物理尺度及裁剪后的 origin。

建议工程门槛：解析点坐标误差低于 0.1 探测器像素；圆柱中心射线积分相对误差不超过 5%，且积分步长减半后变化不超过 1%。这些是项目提出的离散化检查，需在固定体模上预先冻结。圆柱完整扫描 FDK 检查尺度与位置；三/四投影 FDK 不要求达到完整扫描精度。真正器械的细杆保真另作网格收敛测试。

FDK 滤波器、角度权重、距离权重、截断处理和后端版本必须记录。原文未公开的数值细节保留为实现选择。

### 7.2 推理契约

推理入口只读取测试投影、标定和已训练权重，不读取测试真值来生成网络输入、选择 ROI 或定位器械。

| 方法 | 完整执行顺序 |
| --- | --- |
| A | 全部投影分别 DTE → 一个 FDK 体 → 按训练约定归一化 → 相邻 C 层滑窗 DTR → 按原层序堆叠 → 概率体与二值体 |
| B | 三幅投影分别 DTE → 同一物理网格的三个独立反投影体 → 3D DTR → 概率体与二值体 |

DTE 默认整幅推理，按网络总 stride padding 后去除 padding，恢复原探测器坐标。A-DTR 在显存允许时使用完整 xy 切片；B 参考推理使用 `3×256³` 输入，不把训练 `128³` 块当作完整测试视野。

如必须分块，固定 overlap、边界和融合权重，保存覆盖图，并与可运行的整幅/整体验证结果比较；分块推理作为明确的运行选择，不能未经检验宣称与整幅严格等价。A 默认概率阈值 0.5；B 默认 0.5 属于项目选择。禁止通过测试真值删除小连通域或调整阈值。

每例保存 DTE 输出、FDK 或三通道反投影的可检查样本、最终概率/二值体、坐标元数据、运行日志及阶段耗时。可配置中间结果压缩策略，但保留失败案例的完整证据。

## 8. 统一评价协议

### 8.1 测试对象与网格

课题主评价使用同一批纯支架病例、同一份输入投影、同一真值和预定义 ROI；联合器械场景另外报告，不能把导丝性能混入“支架 Dice”。

论文参考线保留原生网格；课题线默认先保留各法原生内部网格，按真实标定生成输入，再映射至测试真值定义的共同评价网格。评价网格由数据分辨率与视野决定，在查看测试预测前冻结，不能仅为了改善某法分数而选择。

概率体按物理坐标线性重采样一次，再用固定阈值二值化；离散真值用确定的体素化或最近邻规则。保存原生输出，额外检查重采样对细杆的影响。粗网格上采样不会增加实际空间分辨率，B 的 0.6 mm 网格尤其需要明确这一点。

若原生网格无法覆盖课题器械尺度或共同 ROI，则先定义具名的网格适配版本，并据此重新生成训练数据与训练 DTR。不能静默裁掉超出视野的器械或仅改推理 spacing。改网格后的结果属于课题适配，不属于原论文条件。

### 8.2 必报指标

| 层级 | 指标 | 解释 |
| --- | --- | --- |
| DTE | MAE；前景/背景分区误差；有可比真值时另算 MAPE | 标签必须是连续投影值，报告强度单位 |
| 三维分割 | 每例 Dice、precision、recall | 统一阈值、ROI和网格；不得跨病例先汇总所有体素冒充病例平均 |
| 三维结构 | 预测骨架→真值骨架、真值骨架→预测骨架的平均最近邻距离，mm | 两个方向分别报告，不能只给两者平均值 |
| 失败情况 | 空预测、视野截断、流程失败及严重离群病例 | 分母包括全部预定测试病例，不能静默剔除 |
| 运行 | DTE、几何、DTR及总时延，峰值显存 | 附输入尺寸、视角数、硬件、框架、精度和数据传输范围 |

对非空骨架集合 P、G，定义 `d(P→G)=mean_{p∈P} min_{g∈G} ||p-g||₂`，坐标先转换到世界坐标 mm。记录骨架化算法和版本；B 参考采用原文 Lee 3D 骨架化的可核验实现。该量是骨架平均最近邻距离，不命名为表面距离或 Hausdorff 距离。

主测试真值应非空。非空真值遇到空预测时 Dice=0、recall=0、precision 未定义，骨架距离标为失败且不伪造有限值；用失败率加成功病例条件分布共同报告。背景空场景作为单独负对照，明确双方为空/单方为空的约定。

### 8.3 原文评价补充

A 的 MAPE 需对齐原文工具像素范围及 3×3 中值滤波处理；无可比实测标签时不报告为原文 MAPE。A 的 100 μm 容差 precision/recall 涉及原文真值膨胀/腐蚀，需把确切计算约定核实并记录。若自行选择距离容差公式，另命名为项目指标，不冒充表 4 原指标。

A 表 2 的 `0.794±0.065` 属于 C=5 模拟验证 DTR；表 4 的支架 Dice `0.63±0.04` 属于完整流程实测。B 的 `77.5%` 属于三通道模拟验证 Dice，`72.3%` 属于单通道；实测纯支架场景表 1 的双向距离为 `0.36/0.28 mm`。这些仅为来源与口径核对锚点，不作为无原始数据时的硬性达标线。

### 8.4 重复实验与计时

课题主比较建议至少 3 个训练种子；同一对 A/B 使用相同冻结测试病例。报告每种子的病例结果、均值和离散程度。统计独立单位为实体支架/患者，而非切片或 patch；同一实体的多位置、多噪声采集按实体分组。若计算置信区间，使用配对、按实体分组的重采样；训练种子波动单独报告。

主比较的每个种子默认独立训练 DTE 和 DTR。同一方法、同一种子的 C/通道数消融可复用其已冻结的 DTE，以隔离 DTR 改动；改变视角必须重新生成并训练 DTR。只有 DTE 的训练来源、几何分布、预处理及架构均未改变时，才允许复用 DTE，并记录检查点哈希。若资源限制下只重复 DTR，须明确报告为固定 DTE 条件下的波动。

计时先预热并在测量边界同步设备，分别报告计算时延及包含数据传输的总时延。B 原文约 40 ms 是一幅 1024² 的 DTE，约 260 ms 是 `3×256³` 的 DTR，均有特定 RTX 3090/TensorFlow/混合精度条件；不能将二者直接当成三投影完整流程实测时间。

### 9.1 必需主实验

| ID | 方法和条件 | 用途 |

| REF-B | B，三幅相邻 60°，三通道 | 原文参考条件的实现核对 |

### 9.2 消融

第一批完成 TASK-A 的 C=1/3/5 与 TASK-B 的三通道/单通道对比，每个输入定义独立训练。当前仅有 B 原视角单通道配置，须新增课题视角的单通道配置。

第二批在参考线补 A 的 C 消融、二/三/四投影消融及四投影 45°/30°/22.5° 间隔消融，B 补单通道参考消融。A 的减少投影数与减小角距是不同实验，准确视角按原文核实后冻结，不能合并成三投影 0–60°。

后续可选实验为统一支架训练集、匹配内部网格、B 错误增强强度、A 加入 DTE 错误增强。它们均为控制或改进实验，另设名称，不覆盖论文主基线。误差强度与物理扰动水平从训练/验证或标定得到，不设未经依据的“真实噪声”。

## 11. 验收测试

只增加能检测真实实验错误的测试，不以测试数量评价完成度。

1. **结构**：检查 A 阶段/瓶颈约定，B 通道及维度，损失公式，输出范围，真实数值梯度；原尺寸资源检查与 meta 测试分开。
2. **数据**：实体/患者跨集合泄漏、物理单位、哈希变化、固定和随机采样、在线配对刷新、实际每轮数量、所有输入和标签同步变换。
3. **归一化/恢复**：验证和测试不更新统计；恢复后样本序列与统计一致；不把冻结统计当成 A 在线运行统计。
4. **几何/推理**：点和杆件的方向、坐标、视角顺序、裁块 origin；A 滑窗还原层序；B 保持三通道；无真值访问；边界与分块覆盖。
5. **评价**：完全一致、完全不相交、空预测、不同 spacing 和网格变换。骨架位移测试使用隔离点或已知结构，不能假定任意骨架整体平移一个体素后最近邻距离都等于一个体素。
6. **集成**：小型非对称三维器械体模的训练/推理/评价闭环；不得将骨架/真值直接作为 DTE 或 DTR 推理输入而冒充完整流程。
7. **实验**：结果表能追溯到具体检查点和病例；同一测试集、不同种子与消融不会互相覆盖；失败病例不会从汇总中消失。

最终验收不能仅依据低训练 loss。必须同时检查阶段输出、独立测试指标、失败率、数据来源和声明等级。
