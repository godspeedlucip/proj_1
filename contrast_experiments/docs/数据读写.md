# 投影和三维体的数据读写

本接口位于 `stent_repro.io`，支持灰度 `.tif` / `.tiff`、`.npy` 和本项目的 `.npz` 格式，不执行缩放、归一化、插值、坐标变换或重建。建议使用 `.npz`，它把数据和元数据保存在一个压缩文件内；`.npy` 和 TIFF 的元数据存放在同名附加 `.json` 的文件中（例如 `scan.npy.json`），移动数据时必须一同移动。外部 `.npy` 和灰度 TIFF 可直接读取，但没有旁车文件时返回空元数据，不会读取 TIFF 自带的物理标签或推测几何。`.npz` 必须是本接口写出的格式，不支持任意第三方 NPZ 键结构。

- 投影：单张 `[v,u]` 或投影栈 `[view,v,u]`，读出一律为 `[view,v,u]`，保持输入顺序和原 dtype。`angles_deg` 的顺序必须与图像顺序一致；`pixel_spacing_mm` 按 `[u,v]`。
- 三维重建或真值：`[z,y,x]`。`spacing_mm` 和 `origin_mm` 按物理坐标 `[x,y,z]`；`direction` 为将索引坐标轴 x、y、z 映射到物理坐标的 3×3 方向矩阵（列对应 x、y、z）。未提供几何时，不能假定其与其他体对齐。
- 数值必须是有限的实数或布尔值；不读取 pickle。角度、尺寸、间距和方向矩阵会做基本检查，但无法检查投影与角度实际是否配准。
- 投影值可以是原始探测器灰度、经过校正的强度或线积分；请在 `units` 和额外元数据中明确记录。该模块不自动执行暗场/平场校正或负对数变换。

```python
import numpy as np
from stent_repro.io import save_projections, load_projections, save_volume, load_volume

# 用自己的数组替换，数组顺序须与角度对应。
projections = np.zeros((3, 960, 1240), dtype=np.float32)
volume = np.zeros((128, 128, 128), dtype=np.uint8)
save_projections('projections.npz', projections, {
    'angles_deg': [0, 30, 60],
    'pixel_spacing_mm': [0.308, 0.308],
    'geometry': {'sdd_mm': 1200, 'sid_mm': 785},
    'units': 'line_integral',
})
save_volume('truth.npz', volume, {
    'spacing_mm': [0.1, 0.1, 0.1],
    'origin_mm': [0, 0, 0],
    'direction': [[1,0,0], [0,1,0], [0,0,1]],
    'units': 'binary_mask',
})
projections, projection_metadata = load_projections('projections.npz')
truth, volume_metadata = load_volume('truth.npz')
```

样本清单用于记录投影和三维真值的配对，文件路径相对于清单所在目录。可以选择性提供生成该场景的所有实体 `model_ids`；若同一 ID 出现在不同 split，读写清单会拒绝。未提供 ID 时无法检查模型泄漏。清单只是文件配对，不表示已经完成数据处理或训练。

```python
from stent_repro.io import save_manifest, load_manifest, load_case
save_manifest('cases.json', [{
    'id': 'case001', 'projections': 'projections.npz', 'volume': 'truth.npz',
    'split': 'train', 'model_ids': ['stent001', 'wire001'],
}])
case = load_case(load_manifest('cases.json')[0])
# case['projections'], case['volume'], case['projection_metadata'], case['volume_metadata']
```

保存模型输出时同样调用 `save_volume`，将 `units` 设为 `probability` 或 `binary_mask`，并传入真实输出网格的 `spacing_mm`、`origin_mm` 和 `direction`。数据格式不是训练或重建算法；目前尚未将读写接入完整重建流程。

## TIFF 单张、多页和投影序列

`load_projections` 支持单张灰度 TIFF 和以页为视角的多页 TIFF；`load_volume` 将多页灰度 TIFF 按 `[z,y,x]` 读为三维体。图像数值和 dtype 保持不变，不进行窗宽窗位映射。彩色 TIFF 被拒绝；复杂 OME-TIFF 或 RGB 数据需要先明确转换轴和通道。

多个独立 TIFF 文件必须显式提供顺序；不要依赖文件系统返回顺序。`angles_deg` 与传入路径顺序一一对应：

```python
from stent_repro.io import load_tiff_sequence, save_tiff_sequence, save_volume

projections, info = load_tiff_sequence(
    ['view0.tif', 'view30.tif', 'view60.tif'],
    {'angles_deg': [0, 30, 60], 'pixel_spacing_mm': [0.3, 0.3],
     'units': 'detector_intensity'},
)
# 写到空目录；生成 view_00000.tif 等文件和记录顺序、元数据的 sequence.json。
save_tiff_sequence('ordered_views', projections, info)
projections, info = load_tiff_sequence('ordered_views')
# 或直接把 ordered_views 作为样本清单 projections 路径，load_case 会读取。
# save_volume('reconstruction.tif', volume, volume_metadata)
```

单文件 TIFF 元数据存于 `reconstruction.tif.json` 等旁车文件；独立文件序列的元数据存于其 `sequence.json`。这些文件应与 TIFF 一起保留。已有无清单的 TIFF 目录需要先按角度排列路径并传入 `load_tiff_sequence`；不能仅凭文件名推断角度。
