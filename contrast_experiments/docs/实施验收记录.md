## 2. 独立审查与修复

独立 reviewer 审查后完成一次修复及回归验证，未重复派发审查。新增 `tests/test_review_regressions.py`，其中七个初始用例先失败再通过，随后补充阶段预检匹配、损坏投影和前处理几何冲突的覆盖。全部回归合并后为 110 项。

| 审查问题 | 落地处理 |
| --- | --- |
| 同形状投影的标定声明冲突未拦截 | 前处理、推理检查声明的采集几何；正式配置要求一致的 calibration_id |
| 推理输入未固定，矩阵只在开始比较数据 | 独立 freeze 命令；正式推理要求冻结契约；矩阵训练前冻结测试投影/真值，并逐任务复核 |
| 损坏 NPY/NPZ 可中断整批评价 | I/O 将 EOF/坏 ZIP 转为受控错误；推理/评价保留失败病例和分母 |
| 旧检查点新增字段不兼容，恢复可能覆盖 best | 仅对等价旧默认字段迁移，并沿用历史最佳选择值 |
| 正式训练未强制绑定实际资源测量 | 模型分配前验证实际前向/反向/优化器步骤报告；绑定阶段、batch/patch、设备和运行环境 |
| DTE 缓存只依赖可编辑任务名称 | 升级为配置、种子、几何、采样与源数据指纹的哈希；DTR 消融可复用同一合格 DTE |
