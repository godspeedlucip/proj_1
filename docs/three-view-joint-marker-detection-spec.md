# Phase 1：固定间隔锥束投影的三视角联合 Marker 检测 Spec

状态：软件链路已实施；真实锥束标定和折外性能验收待数据到位。本文定义现有 Phase 1 的下一版检测方法；未改变的病例清单、折外预测和 Phase 2 交接规则继续遵守[现有 Phase 1 spec](marker-detection-codegen-spec.md)与[交接契约](../../docs/phase1-phase2-handoff-design.md)。现有单图 U-Net 加候选几何搜索作为对照基线保留。

## 1. 目标与验收口径

对同一静止支架状态的三张锥束 X 射线投影进行**一次联合检测**，返回每张原始投影中的两个无序 Marker 中心，即每病例三个二维点对。模型必须在最终热图产生前利用其他视角的信息，联合训练三张图的输出；仅把三个独立检测结果送入现有 `fuse_three_views` 不满足本目标。

本版不以恢复三维 Marker、修改 Phase 2 分割网络或直接移植 AdaFuse 的人体关节权重为目标。三维几何仅为二维联合检测提供采样约束和诊断。

主要评价是原图像素坐标下的无序 `PairAcc@τ`、平均点误差及三视角六点全正确率，辅以弱响应、双点靠近、强假峰病例的分层结果。主指标 `PairAcc@τ` 以**全部视角**为分母，`invalid` 记为失败；另报告仅在有效视角上计算的条件准确率和 `invalid_rate`，防止模型通过多拒绝困难病例提高表面准确率。平均点误差仅在有效预测上定义，须同时显示有效视角数。模型是否优于当前 Phase 1，必须由相同支架组划分、相同真实或物理可信的锥束投影数据上的折外比较决定。当前 `synthetic.py` 的噪声加 Gaussian 圆点只用于软件 smoke，不能作为定位收益证据。

## 2. 输入、几何和输出契约

- 沿用 UTF-8 JSON manifest：每个 `case` 有 `case_id`、`group_id` 和恰好三个 `views`；每个 view 沿用 `view_id`、`angle_deg`、`projection_path`、训练/评价用 `marker_xy`、`P`，以及可选 `mask_path`。沿用二维单通道 TIFF、同病例三图同尺寸、原图 `(x=列,y=行)` 坐标约定。联合模型的同一训练/预测包须使用同一探测器像素网格 `[H,W]`；若曾重采样，`P` 必须对应重采样后的网格。不新增逐病例位置输入字段。`mask_path` 不进入 Phase 1 模型。
- 三个角度模 360° 后为 `[n·30°, (n+1)·30°, (n+2)·30°]`，`n` 为整数；探测器、源到等中心距离、源到探测器距离及其他几何参数固定。内部按角度的循环顺序规范化三图，不能依赖 JSON 数组顺序；输出仍按各自 `view_id` 回填。角度校验容差默认为 `1e-3°`，明确拒绝重复、缺失或不符合 30°/30° 间隔的联合模型病例。旧模型的宽松 `≤60°` 校验不因本方案被删除。
- 锥束投影矩阵 `P` 保留在 manifest 中，供离线验证、几何采样构建、诊断及旧基线使用。联合模型的可学习图像分支只接收三张投影，不把 `P`、角度或真值坐标拼成图像通道。由已知固定扫描器几何得到的极线采样关系作为模型版本的一部分冻结；每个病例用其 `P` 检查该关系，偏差超出验证集确定的像素容差时明确报错，不能静默套用固定采样图。
- 最终 JSON 沿用 `phase1_marker_case_v1` 的三个视角记录：每视角两个无序浮点 `marker_xy`，以及 `image_size`、`error_radius_px`、`pair_status`、`q_pair`、`fusion_mode`；病例级来源字段、`geometry_id` 和 fold 约束不变。`fusion_mode=three_view` 表示三个视角参与最终检测；具体 `joint_epipolar_v1` 架构、权重、固定几何、解码与几何搜索配置由 `model_id` 和来源登记表区分。未通过独立校准时有效点对继续输出 `q_pair=null`。
- `train`、`predict`、`evaluate`、`export-fold` 命令及其现有位置参数保持；`model_type=joint_epipolar_v1` 选择新模型，缺省 `model_type=single_view_v1` 暂保留旧行为，直到真实折外评价支持切换默认值。新模型 checkpoint 格式为 `marker_joint_epipolar_checkpoint_v1`，旧 checkpoint 仍按旧路径推理。Phase 2 的 point/band/validity 输入与病例连接方式不变。

## 3. 联合检测模型

### 3.1 结构

输入张量为 `[B,3,1,H,W]`。三个视角共用现有 `MarkerUNet2D` 的权重，得到初始单通道 Marker logits `L0[B,3,1,H,W]`。融合模块在**未做 Top-K/NMS 前**，以固定锥束几何将其他两个视角的热图软证据投向当前视角，并由小型卷积细化头输出 `L1[B,3,1,H,W]`。因此目标视角的最终预测对其他两张输入图可微地依赖。

每个目标像素对应另一个视角的一条极线；在有效探测器区域沿线均匀采样热图，以带温度的归一化 `logsumexp` 汇集证据，温度默认 0.1。不能对原始投影灰度作像素对齐或在融合前硬截断为 Top-K。采用分辨率的 `1/4` 进行极线汇集，先用局部最大池化保留小 Marker 峰，再把支持图双线性上采样到原图；每条线默认 32 个采样点。实现须按目标图块分块采样，避免在 1024² 图像上一次性展开全部极线张量。几何变换、无效线段掩码与采样网格必须与图像裁剪/padding 一致，输出最终回到原图尺寸。

融合头接收目标视角初始 logits、来自另外两视角的支持图，以及两个可学习的来源质量权重；权重由初始热图及跨视角一致性摘要估计，归一化后仅用于融合，不解释为已校准的 `q_pair`。融合头对 `L0` 作残差修正，零初始化末层，使初始行为接近单图模型。两个 Marker 共用一个热图通道并保持无序：不能按左右像素位置给两个物理点指定固定身份。极线支持有把另一 Marker 或假峰传播成线状响应的风险，融合头必须同时看到目标自身证据和两个来源证据，并通过三视角监督学习抑制伪峰。

### 3.2 训练与推理

- 训练样本单位是 `case`，不能把三个 view 展平后作为互不关联的样本打乱。`batch_size` 在新模型中表示病例数，默认 1；每个病例的三图按规范化顺序进入网络。保持按原始 3D 支架模型 `group_id` 分组的训练、验证、测试及 Phase 2 fold 内的 group OOF 导出。
- 原有两个 Gaussian 取逐像素最大值的标签和正样本加权 MSE 继续使用。主损失为三张最终热图的平均损失；初始热图加辅助损失，`aux_loss_weight` 默认 0.25，避免初始分支退化。先不增加显式三维坐标回归或三维损失；3D 点仅作可选几何诊断。空间增强如改变像素坐标，必须同步变换极线几何；首版只启用不改变空间坐标的强度增强。
- 推理时从三张最终热图提取候选，然后沿用现有无序双 Marker 候选枚举、三视角几何搜索及已冻结的回退规则。另保存初始/最终热图和候选召回诊断，以分辨收益来自可学习联合检测还是旧几何搜索。`predict` 对每病例只运行一次联合模型，不调用三次独立 `predict_heatmap`。
- 旧单图模型作为 V1 基线；新模型的主比较为 V2：联合热图加**相同配置**的候选几何搜索。另报告 V2 不用候选几何搜索的消融，避免把后处理收益误记为网络收益。训练和推理所需固定极线映射要由同一版本几何产生并记录摘要。

## 4. 几何、数据和失败条件

1. 使用真实锥束投影器导出的 `P` 或独立标定点，验证任意物理 3D Marker 投到三图后的极线距离及重投影误差；确认不同 `n` 的相对 30°/60° 映射在既定容差内一致。这个检查先于模型训练。单有角度数值和相同探测器尺寸不足以证明映射正确。
2. 零有效极线采样、非有限 `P`、几何版本不匹配、角度排列不合法、三图不同尺寸必须给出明确错误。支持图只从有效探测器采样，不能让越界 padding 产生假响应。
3. 单视角热图里两个峰可能合并。联合训练须报告真值双点进入最终 Top-K/Top-L 的比例；若候选召回不足，几何搜索不可能补回缺失点。对一视角弱响应、另一视角强假峰、两点接近和角度跨 0° 的病例分别评估。
4. 真实/可信 DRR 数据必须覆盖支架与背景沿锥束射线叠加、Marker 强度变化、噪声及近距离投影；按原始 3D 支架 `group_id` 切分，不让同一模型的不同 `n` 跨训练与测试。现有 Gaussian 圆点合成数据仅检查张量、几何和 CLI。
5. 无序双点评价必须使用**整对的一对一匹配**：平均点误差取保持与交换两种排列中总误差较小者；`PairAcc@τ` 在存在一种排列使两个点都不超过 `τ` 时记为成功。不得对每个点各自取两种排列的最小值。

当前仓库没有可据以验收真实收益的锥束病例集或独立标定资产。实现阶段可用解析锥束投影矩阵与小型人工热图验证软件；实际扫描器/仿真器的 `P`、对应原图、Marker 真值和按支架分组的保留病例是正式几何冻结与 V1/V2 性能判断的外部数据前提。本次软件方案不包含采集或制作这批数据；缺少它们时验收只能到软件链路，不能宣称检测精度提升。

## 5. 验收和参考

软件验收：新旧 checkpoint 都能经同一 CLI 推理；新网络输出原图大小的三视角热图，改变来源视角图像会影响目标视角最终热图且梯度能回传；固定几何对跨 0° 角度仍正确；输出通过 Phase 1 v1 校验和 Phase 2 数据校验；group OOF/held-out 来源完整且不泄漏。真实收益验收另行报告相同 fold 上 V1/V2 的无序 `PairAcc@τ`、三视角六点全正确率、失败率及每例耗时，不预先宣称 V2 更优。

研究参考：[AdaFuse](https://arxiv.org/abs/2010.13302) 的极线热图融合与自适应来源权重；[Cross View Fusion](../../references/papers/06_qiu_2019_cross_view_fusion.pdf) 的联合二维热图监督；[X-ray Marker 检测](../../references/papers/01_huang_2022_robust_landmark_stent_tracking.pdf) 的小目标热图检测。以上只提供模块思路；本任务的锥束几何、双无序 Marker、固定角度与 Phase 2 交接按本 spec 实现。
