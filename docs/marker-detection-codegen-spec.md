# Phase 1：三视角双 Marker 检测系统 Spec（任务优先版）

本文件描述当前已实现的单投影热图检测与候选级三视角融合基线。下一版的三图联合训练与检测见[固定间隔锥束投影三视角联合检测 Spec](three-view-joint-marker-detection-spec.md)及其[实施方案](three-view-joint-marker-detection-implementation-plan.md)；病例清单与 Phase 2 二维点对交接继续沿用本文和交接契约。

首版实施步骤见 [Phase 1 Plan](marker-detection-implementation-plan.md)，跨阶段数据定义见[交接契约](../../docs/phase1-phase2-handoff-design.md)。

## 1. 任务目标与方案选择

本阶段对同一静止支架状态、采集角度位于不超过 60° 窗口内的三张仿真 X 射线投影，检测每张图中的两个端部 Marker。两个 Marker 中心始终在各自投影的视野内；弱响应或两点投影接近仍可能造成检测困难。目标是提高三视角六个点全部正确的概率，同时保留每个视角独立检测的质量分析。使用本项目自行实现的 PyTorch 2D U-Net，三个视角共享一套权重；三视角候选级融合是正式推理流程的一部分。

本阶段的产物包括每视角原始分辨率热图、Top-K 候选、三视角联合选择出的二维 Marker 对、置信与失败状态，以及用于检查几何一致性的可选三维点。二维坐标是实际定位结果；后续工作可以由这些结果生成空间先验，但不规定本检测网络必须服从某个分割网络的内部通道或训练方式。

方案的优先级如下：

| 层次 | 方案 | 本阶段定位 |
|---|---|---|
| 单视角检测 | 共享 U-Net → 双峰热图 → 峰值候选 | 必做，决定候选召回上限 |
| 三视角融合 | 投影几何约束下的候选匹配与重投影评分 | 必做，最终主输出 |
| 可学习热图融合 | 极线支持图与小型融合头 | 实验增强，只有证明收益才进入最终模型 |

**首版代码交付**只实现一套简单的单通道 2D U-Net、Gaussian 热图训练、峰值候选提取、三视角候选几何选择与单视角回退，并提供训练、推理、评价和按 Phase 2 fold 导出预测的可运行命令。响应图输入、残差块、Patch 预训练、可学习跨视角热图融合及各项消融留到主链路跑通后；它们不阻塞首版交付。

候选级融合是明确的三视角信息融合：一个视角的候选点只有与另两个视角共同构成合理三维位置时才会被保留。完整图像上的跨视角热图采样要对大量背景像素重复计算，且会沿极线传播误峰，因此先以候选级融合为主。

[Phase 2 spec](../../phase_2/docs/marker-guided-nnunet-codegen-spec.md) 说明了一个可能的下游消费者：它用已得到的二维坐标生成 point/band 先验。两阶段共同遵守[交接契约](../../docs/phase1-phase2-handoff-design.md)。该关系用于检验坐标可导出性，不作为 Phase 1 网络结构、损失或验收指标的来源；下游 E6 所需的解剖学端点身份也不在本阶段凭像素左右顺序臆造。

## 2. 必须先确认的数据契约

- 一个 `case_id` 对应同一静止状态下的三个视角，三个视角一起进入同一个 train/val/test 分组。
- 每张投影的两个物理 Marker 中心均在原图有效像素范围内；`invalid` 表示检测或几何选择失败，不表示 Marker 移出视野。标注时仍应记录两点投影过近、图像响应重叠或低对比度等难例，不能把这些难例从评价中删除。
- 每张投影需要两个 Marker 中心真值，优先由真实 3D Marker 中心和仿真几何投影产生；也允许经复核的手工 2D 标注。二维支架 Mask 的端点不自动等于 Marker 真值。
- 每个视角必须能提供与当前图像对应的投影几何 `P_v`，或提供可生成同等投影、反投影和重投影操作的几何对象。先从仿真器导出并用已知 3D Marker/标定点验证。三视角正式融合依赖此契约。
- 病例清单记录三个实际采集角度、旋转轴/投影几何版本和两两角差；不假设三个视角在 60° 窗口内均匀分布，也不预设某个通用的最小角差。以真实几何计算有效视差，并在不同角度间隔上分别检验三视角融合是否优于单视角。
- 坐标统一为原始图像 `(x=列,y=行)`，保留浮点亚像素值、`width`、`height`、`view_id`、`case_id` 和投影几何版本。
- 如果网络输入经过缩放、裁剪、翻转或旋转，用二维变换 `T_v` 同步映射标签与几何：能表示为齐次图像变换时使用 `P'_v=T_v P_v`。推理导出前统一用 `T_v^{-1}` 回到原始图像坐标。不能拿变换后的候选点与原始 `P_v` 混用。
- 几何验证必须在训练/验证资料上报告真值重投影误差、Marker 响应可分辨性、有效视差和三角化稳定性；用真值点加入与实际定位误差相称的像素扰动，检查候选选择对小误差的敏感程度。阈值相对于目标定位容差及 Marker 像素直径确定，不能只凭“三张图静止”或小重投影误差推定几何约束可靠。
- 按原始 3D 支架模型分组切分；同一模型仅改变角度、姿态或噪声的投影不得跨分组泄漏。

## 3. 单视角网络

### 3.1 输入和骨架

实现一个简单的 `MarkerUNet2D`，三个视角逐张运行且共享参数。首版只使用原始投影单通道；`[raw, morphology, LoG]` 作为后续可选输入，morphology 的黑帽/顶帽方向届时由 Marker 实际亮暗极性决定。推理时不得读取支架 Mask。

推荐编码器宽度 `32/64/128/256`、三次 `×2` 下采样、同尺度 skip、上采样解码、全分辨率 `1` 通道 logits；首版不加入 residual block 或额外注意力模块。归一化使用 GroupNorm 或 InstanceNorm，小 batch 不依赖 BatchNorm 统计。输入尺寸不整除 8 时做可逆 padding，输出裁回原始尺寸。通道宽度是可调整的工程起点。

### 3.2 标签、损失和训练

两个无序 Marker 在单通道热图上各生成 Gaussian，并逐像素取 `max`。`sigma` 应相对实际 Marker 像素直径确定；当两点靠近到两峰合并时单独统计失败病例，不能把无法解开的单峰算成普通解码错误。

首版使用可配置的正样本加权 MSE；令 `alpha=0` 即普通 MSE。单独的漏检惩罚留作后续实验：

```text
H = sigmoid(logits)
w = 1 + alpha * H_gt
L = mean(w * (H-H_gt)^2)
  + lambda_fn * mean(relu(H_gt-H)^2)
```

首版设置 `lambda_fn=0`，`alpha` 在当前 Phase 2 fold 允许的训练组内部确定。仍须监测误检数、召回和热图背景响应，避免模型退化为全背景热图；之后若加入漏检项，再对 `lambda_fn` 作独立评估。

首版只实现完整投影训练 `full_only`。Marker 正 Patch 与背景负 Patch 预训练、响应图通道和其它增强方法均为后续实验，不作为生成可运行主链路的前置条件。

### 3.3 候选提取

对单视角热图做局部极大值、NMS 和可选局部亚像素细化，保留 Top-K `(x,y,score)`。`score` 是峰值强度，不直接当作已校准概率。`K=10` 仅为首轮实验配置，和 NMS 半径、峰值阈值一样可在后续实验中调整；同时记录 `Recall@K`、两个 Marker 同时进入候选集的比例、假峰数量和近距离双峰失败率。若真值对常被排除，应调整 K、NMS 半径或解码方式，再优化三视角搜索。

## 4. 三视角融合：候选对的联合选择

### 4.1 无序端点的正确枚举

在每个视角选择两个**不同**候选形成无序候选对。固定第一个视角的一对为临时 `A/B` 参考；第二、第三视角各有“保持/交换”两种相对对应，共 `2×2=4` 种。整体交换三视角中的 `A/B` 是同一个解，不重复计数。这里的 `A/B` 只是三视角内一致的临时身份，不承诺 Phase 2 E6 所需的解剖学端点身份。

例如第一视角按图像横坐标排列为 `(左 A, 右 B)`，第二视角投影方向变化后同一物理 A 可能落在右侧。若禁止第二视角相对交换，就会把两个真实点接错。每个视角内部的两个候选不能被两个轨迹重复使用。

### 4.2 可计算的搜索流程

1. 每视角从 Top-K 候选形成最多 `K(K-1)/2` 个无序点对。用两点峰值分数和**宽松**的投影距离范围排序，保留前 L 对；`K=10,L=5` 只是首轮可配置值，后续按真值点对保留率与搜索成本调整。逐项记录候选召回与点对召回：若真值点对常在这一步被删掉，就增大 L 或放宽点对筛选，而不是调后面的三角化权重。
2. 形成三视角候选对组合，并按上述 4 种相对端点对应枚举。`L=5` 时至多 `5³×4=500` 个原始假设。先用投影几何的极线距离/两视角一致性作低成本预筛；门限要包含标定和定位误差。
3. 对余下每个假设分别三角化两个 3D 点，并将它们重投影到全部三个视角。使用归一化坐标的线性 DLT/SVD 初始化，以三个视角的鲁棒重投影误差进行最终评分。第一版用无权三角化，峰值分数只参与假设排序；再对裁剪后的峰值分数加权 DLT 做消融。峰值分数不能冒充网络学得的几何置信度。
4. 最终评分由六个峰的 `log(score+eps)` 总和与六点的鲁棒重投影误差组成；系数和可靠性阈值只在验证集选择。依据仿真几何检查有限深度、可见性与数值退化。两个 Marker 的物理间距仅在训练集能支持明确范围时用作宽松拒绝条件。
5. 两个视角已形成高可信三维点、第三视角只有一个强候选时，首版按第 6 步的回退/失败规则处理；由重投影引导的弱峰局部重查留待后续实验，测试时始终不得使用真值坐标。
6. 返回各视角无序 2D 坐标对，并分别评价“点对位置是否可靠”和“跨视角 A/B 身份是否明确”。若最佳与次佳只交换身份、各视角选择的两个二维点相同，点对仍可可靠；若它们选择了不同的二维候选且分数相近，则点对标为 `uncertain`。当有效视差不足或三视角选择不稳定时，按验证集冻结的判据回退到 V0 的逐视角点对，逐视角记录 `fusion_mode=single_view_fallback`；不能仅因三维点不稳定就丢弃已有的两个可用二维候选。仅在该视角仍无法形成可审查点对时标为 `invalid`，并保留失败诊断。回退结果与三视角结果分别评估、分别纳入可靠度校准。

实现三角化时，对每个候选二维点 `(u_v,v_v)` 和该视角的 `P_v` 叠加两行 `(u_v P_v[2]-P_v[0])`、`(v_v P_v[2]-P_v[1])`，对行做数值归一化后由 SVD 求齐次 3D 点。两条轨迹分别求解；在三个视角重投影后计算假设分数：

```text
S = mean_{v,k} log(max(s_vk, eps))
    - lambda_reproj * mean_{v,k} Huber(||project(P_v,X_k)-m_vk|| / scale_px)
```

`k` 遍历两个 Marker，`scale_px` 由验证集的标注/标定误差确定。评分只比较通过几何预筛和可见性检查的假设；`lambda_reproj` 与 Huber 阈值在验证集固定。重投影误差使用原始像素坐标，禁止混用网络缩放坐标。分数加权 DLT 只在消融中替换上述无权 SVD，搜索空间和其它评分保持相同。

这一路径借鉴多视角 2D 检测后几何三角化的思想，具体的无序双点枚举、峰值评分、候选对预筛、回退和弱峰重查是本任务设计。三维点用于选择跨视角一致的 2D Marker；若三维点数值不稳定，检测结果须明确标记，且不能只因二维峰值高就声称几何验证成功。DLT/SVD 是初始化，不等于最小化鲁棒重投影误差；可对最终少量假设增加非线性重投影优化并作为独立消融，尤其检查窄角度病例的排序是否改变。

### 4.3 热图层融合消融

可学习极线热图支持图是后续扩展，不属于首版代码。若以后实现，应比较“原热图＋候选几何”和“融合热图＋同一候选几何”，单独报告收益与额外耗时。

## 5. 给下游的定位结果与先验适配

Phase 1 的正式跨阶段输出是**每视角一个结构化检测结果**：两个无序的最终二维坐标、各点定位误差半径、可靠等级、几何诊断，以及可选的点对校准可靠度 `q_pair`。首版未校准时有效点对的 `q_pair=null`。原始 U-Net 热图、Top-K 候选与三维点另存为研究诊断，不要求下游网络直接读取。优先交付结构化结果，因为先验宽度和表达方式应由下游任务选择，而错误热图中的多余峰值不应原样传入分割模型。

每个 `case_id` 有三个 `view_id`，字段约定如下：

```json

  "case_id": "case_0001",
  "group_id": "scaffold_0001",
  "model_id": "marker_unet_mv_v1_fold0_checkpoint",
  "geometry_id": "sim_geometry_v1",
  "calibration_id": null,
  "prediction_source": "group_oof",
  "fold_id": "fold_0",
  "q_tolerance_px": 3.0,
  "association_status": "resolved",
  "views": [
    {"view_id": 0, "image_size": [1024, 1024], "marker_xy": [[123.4, 456.7], [789.1, 654.3]], "error_radius_px": [2.0, 2.4], "q_pair": null, "pair_status": "reliable", "fusion_mode": "three_view", "peak_score": [0.91, 0.88], "reprojection_error_px": 0.7},
    {"view_id": 1, "image_size": [1024, 1024], "marker_xy": [[234.5, 432.1], [765.4, 678.9]], "error_radius_px": [2.2, 2.8], "q_pair": null, "pair_status": "reliable", "fusion_mode": "three_view", "peak_score": [0.86, 0.84], "reprojection_error_px": 0.9},
    {"view_id": 2, "image_size": [1024, 1024], "marker_xy": [[345.6, 410.2], [740.8, 700.3]], "error_radius_px": [2.5, 2.9], "q_pair": null, "pair_status": "uncertain", "fusion_mode": "three_view", "peak_score": [0.84, 0.82], "reprojection_error_px": 1.1}
  ]
}
```

示例数值只是格式说明。`schema_version` 固定本版接口；`group_id` 指向用于切分的原始支架模型，`model_id` 必须标识具体冻结检测流程，包含网络权重、峰值解码和候选几何融合参数。坐标必须是原始图像的浮点像素坐标，`image_size=[H,W]`，`marker_xy` 无序。`peak_score` 是模型响应，不宣称是正确概率。`error_radius_px` 表示经过保留病例评估的定位误差尺度：可先按峰值、重投影误差和最佳/次佳候选间隔分组估计 90% 误差半径，样本不足时回退到总体半径；不能只把固定 Gaussian 标签的宽度当作不确定度。`q_pair` 的严格含义在下节定义；`calibration_id` 和 `q_tolerance_px` 使其可追溯。`pair_status` 为 `reliable`、`uncertain` 或 `invalid`；不够可靠但仍有两个可审查候选时可以保留坐标并标记 `uncertain`，不足两个可信候选时 `marker_xy=null`、`error_radius_px=null` 且 `q_pair=0`。有效点对逐视角附加 `fusion_mode=three_view|single_view_fallback`，`invalid` 时为 `null`；该诊断字段不改变坐标、可靠度和失败字段的含义。`association_status` 单独表示 3D 轨迹身份是否明确，身份歧义不自动否定无序二维点对。若三个视角实际容差不同，逐视角 `q_tolerance_px` 覆盖病例级默认值；完整字段、空值和下游映射以[交接契约](../../docs/phase1-phase2-handoff-design.md)为准。

### 5.1 校准的点对可靠度

对视角 `v` 定义事件 `Y_v(τ)=1`：预测的两个点与该视角两个真值点在**最优无序匹配**下都不超过容差 `τ`。输出 `q_pair_v` 的目标含义是 `P(Y_v(τ)=1 | 本次检测的评分与几何诊断)`，不是峰值强度或三视角重投影误差的简单归一化。容差在原始像素尺度下按 Marker 尺寸及检测用途预先确定；可在当前 Phase 2 fold 的训练组内部通过真值坐标扰动实验检查分割对定位误差的敏感性，再冻结用于校准的 `τ`，不得借用该 fold 的外层验证或测试标签。如果图像分辨率不同，应记录各视角实际采用的 `q_tolerance_px`。

首版可以不训练校准器：有效点对导出 `q_pair=null`、`calibration_id=null`，并保留原始评分与 `fusion_mode`；`invalid` 仍导出 `q_pair=0`。后续若启用校准，优先采用低容量的正则化逻辑回归，使用按支架模型分组的**折外预测**及相应真值拟合；回退样本的重投影误差不可用，不得填零冒充。独立病例上检查 Brier score、ECE 和分箱 PairAcc，测试集只作最终评价。

如果样本量不足或可靠度分箱与实际成功率明显不符，有效检测导出 `q_pair=null`、病例级 `calibration_id=null` 和原始评分/状态，`invalid` 仍按失败回退约定导出 `q_pair=0`。v1 病例记录不混合部分有效视角有校准值、部分有效视角为 `null` 的状态。定位误差半径和点对成功概率应分别报告：前者描述坐标误差尺度，后者捕捉选错峰值等严重失败的风险。三视角六点全正确的病例级概率若以后需要，必须另行校准，不能直接把三个视角的 `q_pair` 相乘，因为这些预测相互关联。

### 5.2 下游先验适配建议

推荐的下游转换器从最终二维点对生成两个**柔性空间先验**，并与原始投影一起输入分割网络；最终点对可能来自三视角搜索或已记录的单视角回退：

```text
point_prior(p) = max_i exp(-||p-m_i||^2 / (2*sigma_i^2))
band_prior(p)  = exp(-d(p, segment(m_1,m_2))^2 / (2*w^2)) * endpoint_taper(p)
reliability_map(p) = q_pair  # 在有效图像区域为常数
```

`sigma_i` 考虑 Marker 尺寸和 `error_radius_px`；`w` 的基础宽度要由当前 Phase 2 fold 训练组支架 Mask 的覆盖需求确定，再按定位误差适度放宽。支架可能弯曲，直线 band 只是待验证的宽松走廊，不能假定覆盖整段金属丝；Phase 2 应以 point-only 对照和分弯曲程度的 Mask 覆盖/背景占比检验它的价值。`invalid` 时两张先验图及可靠度图均为零，让原始图像仍可被分割网络使用。所有图在原始投影几何中生成，之后随图像一起重采样；先验通道不做逐图 z-score，强度增强只作用于原始投影。宽度和可靠度使用规则在当前 fold 训练组内部固定，不借用该 fold 的外层验证或测试标签调整。

Phase 2 的点先验对照 E1-P 使用 `[projection, point_prior]`；三通道 E2 使用 `[projection, point_prior, band_prior]`，均允许 `q_pair=null`。不预先把 point/band 乘以 `q_pair`。E2-U/E5-U 使用 `[projection, point_prior, band_prior, validity_map]`，有效点对取 1、`invalid` 取 0。只有通过独立病例校准审核，E2-Q/E5 才使用 `[projection, point_prior, band_prior, reliability_map]`，并在 E5 残差先验调制处显式使用 `q_l`：

```text
F_l' = F_l * [1 + q_l * beta_l * (2*A_l - 1)]
```

四通道的 point/band 不额外乘 `q_pair`，避免把低可靠度近似抑制两次。`q_l=0` 严格保证**该层残差调制**为恒等，但不能据此宣称整个 E5 网络与 E0 无先验网络相同；不同架构和训练权重仍可能产生不同输出。可靠度图应随空间变换同步处理，不能被灰度增强或 z-score 改写。`q_pair=null` 表示尚无可信校准，只能进入 E0/E1-P/E1/E2/E2-U/E5-U 或明确标记的探索配置，不能作为 E2-Q/E5 的可靠度输入。应比较同架构 `q_l=1` 与真实 `q_l`，再与拼接方案比较，分开判断可靠度门控与新增通道/参数的贡献。Phase 1 负责输出可校准的 `q_pair`，不在本阶段实现分割网络。

### 5.3 供下游训练的折外导出

为了检验真实的检测→分割链路，Phase 1 应支持按支架模型分组、**按 Phase 2 fold 分别打包**的折外预测导出。对某个 Phase 2 fold 的训练组，每个病例由没有见过该支架组、也没有借用该 fold 验证/测试组的检测模型推理，三视角一起留出，记录 `prediction_source=group_oof`；该 fold 验证病例由只在其训练组上拟合的冻结检测器推理，记录 `prediction_source=held_out`。最终测试病例由只用允许开发训练组确定的冻结流程推理，同样记录 `held_out`。同一病例在不同 Phase 2 fold 可有不同预测记录，不能复用全局单份 JSON。每条记录保存 `group_id`、Phase 1 `fold_id`、具体冻结流程 `model_id` 与 `calibration_id`；包级保存 `phase2_fold_id` 和该 fold 的组划分。另交付来源登记表，列出各检测流程的权重拟合组、参数选择组及校准器拟合组、容差及独立校准审核报告，供 Phase 2 逐例验证无泄漏；只有 `fold_id` 字符串不足以证明折外。下游主实验用这些预测结果训练和测试，使训练阶段也包含真实的坐标偏差、低可靠度与失败病例；使用真值 Marker 构造先验只能作为上限对照。折外导出与单独校准都不得借用该 fold 验证或最终测试真值。

## 6. 首版验收与后续实验

首版验收以**整体代码可运行**为准：从病例清单加载三视角投影与几何，训练共享 U-Net，保存并恢复 checkpoint，导出热图、候选和符合交接契约的三视角病例 JSON；随后按 Phase 2 fold 产生训练组折外预测和验证/测试组冻结预测。至少用一组带真值的合成病例跑通训练、推理、几何选择、回退和 JSON 校验。真实数据上的定位性能及下表消融属于后续研究评价，不阻塞代码首版完成。

| 组别 | 检测与融合 | 目的 |
|---|---|---|
| S0 | 原图简单 U-Net、可配置加权 MSE、完整图训练、单视角峰值 | 首版检测器 |
| S1 | 响应通道、漏检项、Patch 预训练等增强 | 后续实验，不阻塞首版 |
| V0 | S0 候选 + 单视角点对评分 | 首版回退路径；后续作为对照 |
| V1-G | S0 候选 + 三视角联合搜索，不启用单视角回退 | 后续用于分离几何收益 |
| V1 | S0 候选 + 第 4.2 节三视角联合搜索及冻结的单视角回退 | 首版正式二维定位输出 |
| V1-R | V1 + 弱峰几何引导局部重查 | 验证其他视角能否补回一个视角中的弱响应 |
| V2 | 融合热图 + 与 V1 相同的候选几何搜索 | 判断热图层融合是否额外有效 |

主要检测指标：两个点都进入 Top-K 的比例、真值点对进入 Top-L 的比例、无序 `PairAcc@τ`、每张图定位误差/误检、三视角六点全成功率、低置信度/失败率、推理时间。`τ` 在原始像素坐标下按 Marker 直径与实际定位精度需求选取，并参考当前 Phase 2 fold 训练组内部的坐标扰动敏感性。几何诊断包括真值与预测的重投影误差、有效视差、三角化稳定性、实际角度间隔及 `fusion_mode` 回退率；按角度间隔和两点投影接近程度分桶比较 V0、V1-G、V1，避免只报告总体收益。校准诊断包括 Brier score、ECE、可靠度分箱中经验 PairAcc 与 `q_pair` 的对应关系，以及不同拒绝阈值下的覆盖率/错误率。记录每一阶段的候选召回，区分网络漏检、候选裁剪、跨视角选错和几何回退。

后续研究评价再在同一划分上比较 S0、S1、V0、V1-G、V1、V1-R 与 V2，并逐项消融增强模块。`K`、`L`、NMS 半径和几何/回退阈值可在当前 fold 允许的训练组内部按点对保留率、二维定位收益与推理成本调整，外层验证/测试组保持冻结；分数加权 DLT 和最终假设的非线性重投影优化也留作后续独立比较。正式性能报告至少三个随机种子，按支架组统计。

验收至少验证：预测文件每例三视角完整且三个采集角度位于指定 60° 窗口；真值与所有有效预测坐标在原图界内；坐标变换往返一致；同一支架组不跨数据集；用已知真值点构造的几何搜索能找回正确对应；第二/第三视角相对交换时仍找回正确对应；近距离双点、候选不足和错误几何均报告明确状态。构造有效视差不足但单视角仍有双候选的病例，确认输出 `single_view_fallback` 而非无依据的 `invalid`；无双候选时才按失败契约导出。有效检测的 `q_pair` 为数值时必须在 `[0,1]`、有对应 `q_tolerance_px` 和 `calibration_id`；无效检测约定 `q_pair=0`，可以没有校准器；校准不足的有效检测返回 `null` 而不冒充概率。折外记录必须通过 `fold_id` 与来源登记表核对，证明预测模型及校准器未使用本支架组训练。最终是否接入下游支架先验属于后续独立实验，不改变本阶段以 Marker 定位为核心的评价。

## 7. 代码范围

代码位于 `phase_1/`，独立于 `phase_2/nnUNet/`。首版包含数据校验、简单 `models/unet2d.py`、热图标签与损失、峰值解码、几何候选搜索，以及训练/推理/折外导出和评价入口；可学习热图融合等扩展暂不实现。预测产物由第 5 节定义；后续消费者可以编写各自的转换器。

核心接口应保持三个层次，便于分别替换网络、峰值解码和几何搜索：

```python
logits = unet(images)                  # [B, C, H, W] -> [B, 1, H, W]
candidates = decode_heatmap(logits)   # each view -> list[(x, y, score)]
result = fuse_three_views(
    candidate_sets, projection_geometry, config
)                                     # 3 x 2 points + status + diagnostics
```

训练时三个视角可以展平成批次逐张经过共享 U-Net；只有三视角融合步骤要求 `case_id` 内的三张图同时出现。联合搜索不依赖检测网络梯度，便于先训练热图再单独验证几何评分。
